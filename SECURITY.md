# Security Policy

## Reporting a vulnerability

Jari processes page content, clipboard, history, and bookmarks locally, so
please report suspected vulnerabilities privately via
[GitHub security advisories](https://github.com/bymaul/jari/security/advisories/new)
rather than a public issue.

Include the Jari version, browser + version, and steps to reproduce where
possible. I will acknowledge receipt and follow up once the issue is assessed.
