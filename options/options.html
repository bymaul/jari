Keybindings

Click a key field, then press the key (or key combination) to bind it. Backspace clears a binding. Digits 0-9 are reserved for the repeat count and cannot be bound. Prefix keys (g, ;, y) can't be bound alone — pressing one makes the input wait for the next key and binds the pair (g then o binds go); Escape or Backspace cancels the wait.

Disabled sites

Jari is turned off on these sites. Press on a page to toggle it there, or add a host here.
