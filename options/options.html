    Keybindings

    Press +, then press the key combination to add another binding — each command can hold several. Esc cancels. Digits 0-9 are reserved for the repeat count. Any letter can start a multi-key sequence — keep typing keys, then Enter to save. Bindings save immediately.

    Disabled sites

    Jari is turned off on these sites. Press on a page to toggle it there, or add a host here. Use *.example.com to include all subdomains.
