Jari

Simple keyboard-driven navigation settings

Behavior

px

Distance covered by one j/k or h/l press.

Animate scrolling instead of jumping straight to the position.

ms

How long a half-typed g prefix or count waits before clearing.

ms

How long o passes keys to the page before Jari takes over again. Escape exits sooner.

Used for highlights: link hints, headings, the primary button and the showcmd edge.

Keybindings

Click a key field, then press the key (or key combination) to bind it. Backspace clears a binding. Digits 0-9 are reserved for the repeat count and cannot be bound. Prefix keys (g, ;, y) can't be bound alone — pressing one makes the input wait for the next key and binds the pair (g then o binds go); Escape or Backspace cancels the wait.

Disabled sites

Jari is turned off on these sites. Press ctrl+alt+v on a page to toggle it there, or add a host here.

    To open these settings anytime, press ; s on any page (or find Jari under chrome://extensions).
