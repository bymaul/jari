# AGENTS.md - Jari

Keyboard-driven browser navigation extension. ES modules bundled with esbuild
into IIFE bundles (content scripts cannot use runtime ESM imports).

## Commands

```sh
npm install
npm run check         # tsc --noEmit, must be clean
npm run lint          # eslint, must be clean
npm test              # node --test, ~134 unit tests
npm run dev:chrome    # esbuild watch (chrome manifest, sourcemaps)
npm run dev:firefox   # esbuild watch (firefox manifest) + web-ext auto-reload
npm run build:chrome  # rebuild bundles + manifest.json for Chrome
npm run build:firefox # rebuild bundles + manifest.json for Firefox
npm run dist          # zips + firefox xpi (+ chrome crx with CRX_PRIVATE_KEY)
npm run sign:firefox  # AMO sign (unlisted) via WEB_EXT_API_KEY/SECRET
```

## Generated files - never hand-edit

- `content/bundle.js`, `options/options.bundle.js`, `popup/popup.bundle.js`,
  `background.js` (banner: `// Generated by build.ts`)
- `manifest.json` (copied from `manifest.base.json` per target; checked-in
  copy targets Chrome)

Rebuild after touching anything under `content/`, `options/`,
`background/`, or `shared/`, and commit the rebuilt bundles alongside
source (repo convention).

## Layout

- `content/` - content scripts; `content.ts` is the key dispatcher, `commands.ts`
  maps catalog names to actions (`cmd()` helper wraps `COMMAND_CATALOG`)
- `content/hints-elements.ts` - DOM queries/predicates (`isEditable`,
  `isFrameElement`, `getLinkAncestor`, selectors)
- `content/ui.ts` - shared interaction primitives (`ui.consume`,
  `ui.safeFocus`, `ui.dispatchClick`, `ui.focusFrameElement`, toast/pills,
  `buildCategorizedGrid`, `createShadowHost`)
- `content/hint-layer.ts` - shared hint rendering (labels, host, layout,
  `yellow`/`cyan` themes); `content/highlight.ts` - Highlight-API + span
  fallback helpers
- `content/visual/` - visual mode subsystems (`caret-geometry.ts` caret rects,
  `collect.ts` text collection, `word.ts` word motion,
  `motion.ts` fallback `Selection.modify` helpers); `content/visual.ts` is the
  mode orchestrator
- `content/find/` - find subsystems (`matcher.ts` `buildMatcher`/`hasUpperCase`,
  `collect.ts` `collectTextNodes`); `content/find.ts` is the bar + highlights
- `content/prompt/` - prompt subsystems (`shared.ts` `promptCss`/`renderText`,
  `list.ts` `renderTitleUrl`/`renderList`); `content/prompt.ts` omnibar +
  `content/palette.ts` command palette share it
- `content/screenshot.ts` - screenshot helpers (`screenshotFilename`,
  `downloadUrl`, `normalizeRect`, `cropDataUrl`); `content/shot.ts` is the
  region-mark mode, `content/scrollshot.ts` the full-page stitch
- `content/scroll.ts` - scroll target + smooth queue (`smoothScrollBy`,
  `shouldSmooth`, `cycle`/`reset`); `content/commands.ts` now imports smooth helpers
- `background/` - service-worker source (`main.ts` + `handlers.ts` aggregator,
  `tabs.ts` tab ops, `bookmarks.ts` bookmarks, `suggest.ts` suggest/search,
  `windows.ts` window focus, `utils.ts` `clampCount`/`getStoredSettings`);
  `shared/` - `url.ts` (URL parsing, scheme policy) + `tlds.ts` (known TLD set)
  + `constants.ts` + `protocol.ts` (message contract) + `search-engines.ts` +
  `page-nav-texts.ts`
- `options/` - options page (`options.ts` main, `engines.ts` search engines,
  `pagenav.ts` page nav texts); `tests/setup.ts` - shared chrome/DOM stubs

## Conventions

- Smallest change that solves the task; prefer existing helpers in `ui.ts`,
  `hints-elements.ts`, `hint-layer.ts`, `highlight.ts`, `keymap.ts`
  (`normalizeHintChars`, `balanceCategories`) over new code.
- Behavior-preserving refactors: verify edge cases (empty tab lists,
  `role=combobox`, clamp semantics, focus-then-activate order) before
  collapsing branches; keep one clear behavior per helper.
- No new abstractions, config, or deps unless necessary. Do not touch
  unrelated code or fix unrelated issues.
- `shared/url.ts` scheme policy (`urlSchemes`, `blockedUrlSchemes`) is
  security-sensitive: keep `normalizeUrl` / `looksLikeUrl` branches explicit,
  do not merge them for brevity.
- Tests cover major behavior only: security branches, pure-logic boundaries,
  core user-facing flows (happy-path + 1-2 edge cases each). Do not add
  copy/text/ordering snapshot tests or combinatorial permutations.
- Tests import `./setup.ts` for window/document/location/chrome stubs;
  per-test DOM fixtures use save/restore (`background.test.ts`
  pattern). Pure-logic suites (`rank`, `keymap`, `url`) need no stubs.
  All suites are `.test.ts`; stub-heavy fixtures write through
  `Record<string, unknown>` casts and `as unknown as typeof chrome.*`
  at namespace swaps/deletes.
- TypeScript is erasable-syntax-only (Node strips types natively): no enums,
  namespaces, or parameter properties; type-only imports use `import type`;
  cross-module imports carry explicit `.ts` specifiers.
  `Settings`/`RawSettings` live in `content/keymap.ts`; the message contract
  lives in `shared/protocol.ts` (`background/main.ts` is an exhaustive
  per-action router).
- Commit messages: `refactor(scope): ...` / `fix: ...` / `feat: ...`,
  one logical change per commit with rebuilt bundles included.
