History and page addresses — try this now

This page exists so H, L, gu, and gU have somewhere to go. Walk the loop: f the playground link, then H back here, L forward again, gu up to the demo root, gU to the site root.

Serve the demo over HTTP for the full effect (python3 -m http.server in docs/) so gu lands on the playground index. Counts work on history too: 2H jumps back two entries.

Scrolling

j / k / h / l step, d / u half page, gg top, G bottom. Prefix any step with a count: 3j, 2d. This guide is long on purpose — scroll it.

History

H back, L forward through this tab's history, exactly like the extension's history commands. Same-tab hint jumps (f) and plain clicks both add entries you can walk with H and L.

Page addresses

gu goes to the parent URL (drops the last path segment), gU goes to the site root; both strip query and hash, matching the extension. From here, gu yields the demo folder and gU the server root.

Reloading

r reloads the page, exactly like the extension. R reloads too, but cache bypass is browser-privileged: the demo performs a normal reload and says so, while the extension bypasses the cache.

Hints

f same tab, F new tab, gf background tab. Labels use the real charset; typing filters, exact match activates, Esc cancels. Try every link on this page: playground, jari repo, releases.

Find

/ opens find, Enter commits, n / N step through matches (counts work: 2n), Esc hides with n to resume, Enter on a link match follows it. Smart-case: lowercase matches anything, uppercase is exact.

Visual

v drops a caret, h/j/k/l extend the selection, y yanks to the clipboard, Esc exits.

Beyond the demo — needs the install

Tabs (t omnibox, J/K switch, x close, gt manager), yy copy URL, screenshots (gss/gsp/gsr), page jumps ([[/]]), and settings (;e) need the real extension: install jari.
