Get the release

Download the latest release from GitHub Releases. Chrome, Edge, and Firefox are supported (Manifest V3).

Firefox

Install jari-firefox-<version>-signed.xpi directly — it is signed, so Firefox accepts it with one click.

Chrome and Edge

Unzip jari-chrome-<version>.zip, then open chrome://extensions, enable Developer mode, and Load unpacked. The attached .crx is only for enterprise policy deployment with a self-hosted update URL — Chrome rejects hand-installing it with CRX_REQUIRED_PROOF_MISSING.

Firefox development without a release

Open about:debugging#/runtime/this-firefox, Load Temporary Add-on, and select manifest.json. Temporary add-ons vanish on restart. Or build from source below and load the folder the same way — the checked-in manifest.json targets Chrome, so run npm run build:firefox first for Firefox.

Build from source

npm install, then npm run lint (must be clean), npm test, and npm run build:chrome (or build:firefox). npm run dist produces the zips and xpi; npm run sign:firefox signs via AMO (unlisted). Tagging vX.Y.Z runs the release workflow and attaches the install files to the GitHub Release.

FAQ

CRX_REQUIRED_PROOF_MISSING means you tried double-clicking the .crx — unzip the .zip and Load unpacked instead. A Firefox temporary add-on disappearing after restart is normal; install the signed xpi for permanence. Settings sync through your browser's synced storage, so rebinding keys once covers every device.
