Opening settings

Press ;e on any page (or find Jari under chrome://extensions). Everything below is rebindable: press Enter on a binding to save it. Overlapping bindings are allowed but flagged — the single key fires first. Digits 0-9 stay reserved for the repeat count.

Scrolling

Scroll step per j/k/h/l press, plus a smooth-scroll toggle that animates instead of jumping.

Search

A default engine plus custom keyword query engines (g, yt, gh, wiki, r built in; t stays reserved for tab search). Also here: fuzzy matching for the omnibox, suggestion sources (tabs, history, bookmarks), max results, page-navigation link texts, and previous/next page texts.

Clipboard

Copy title + URL as plain text or a Markdown link (yy copies the URL, Y title + URL).

Timing

Sequence timeout for half-typed prefixes and counts, passthrough duration, and the prefix clue: whether available keys show after a prefix like g, and after what delay.

Hints

Hint characters, color theme (yellow, cyan, dark), label size, and an extra clickable selector for elements Jari should treat as clickable (e.g. div.card).

Keybindings

Every command can hold several bindings. Filter by name or key, show unbound-only, reset per command or all at once. Unbound by default: scroll-page down/up and open-hint-in-current-tab — bind them here if you miss them.

Disabled sites

Hosts where Jari stays off (*.example.com wildcards included). Add them here, or press the toggle on the page itself.

Settings sync through your browser — see privacy for where they live. New here? Start with the install guide.
